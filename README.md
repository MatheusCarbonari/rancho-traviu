# Rancho Traviú

Site institucional estático do Rancho Traviú, criado para apresentar o local, o cardápio e as informações necessárias para planejar uma visita.

## Tecnologias

- Astro 7
- HTML semântico
- CSS responsivo com abordagem mobile-first
- JavaScript apenas quando necessário

## Requisitos

- Node.js 22.12.0 ou superior
- npm

## Como executar

Instale as dependências:

```sh
npm install
```

Inicie o ambiente de desenvolvimento:

```sh
npm run dev
```

Gere a versão de produção:

```sh
npm run build
```

Visualize localmente a versão gerada:

```sh
npm run preview
```

## Páginas

- Início (`/`)
- O Rancho (`/o-rancho`)
- Cardápio (`/cardapio`)
- Sua Visita (`/sua-visita`)

## Estado atual

O site possui as quatro páginas institucionais implementadas com layout responsivo, navegação interna e componentes compartilhados de cabeçalho, rodapé e layout base.

Também estão disponíveis:

- Galeria com imagens ilustrativas.
- Cardápio demonstrativo.
- Link de direções pelo Google Maps.
- Imagens responsivas processadas e otimizadas pelo Astro.
- Publicação no GitHub Pages por meio do GitHub Actions.

Antes da publicação oficial do restaurante, as imagens ilustrativas e os pratos e preços demonstrativos deverão ser substituídos por informações reais e confirmadas.
