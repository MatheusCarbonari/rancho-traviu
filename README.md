# Rancho Traviú

Site institucional estático do Rancho Traviú, criado para apresentar o local, o cardápio e as informações necessárias para planejar uma visita.

## Tecnologias

- Astro 7
- HTML semântico
- CSS responsivo com abordagem mobile-first
- JavaScript apenas quando necessário

## Requisitos

- Node.js 22.12.0 ou superior
- npm

## Como executar

Instale as dependências:

```sh
npm install
```

Inicie o ambiente de desenvolvimento:

```sh
npm run dev
```

Gere a versão de produção:

```sh
npm run build
```

Visualize localmente a versão gerada:

```sh
npm run preview
```

## Páginas planejadas

- Início
- O Rancho
- Cardápio
- Sua Visita

## Estado atual

O projeto está em fase inicial. A estrutura mínima do Astro está configurada e contém apenas a página inicial do template, ainda sem conteúdo, identidade visual ou páginas institucionais implementadas.
